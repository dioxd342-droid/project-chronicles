# Project Chronicles

> Working title.

**Project Chronicles** is an original Minecraft MMORPG where players change the world through their actions.

## Current foundation

- Paper 26.2 plugin structure
- Gradle build configuration
- Java 25 toolchain
- `/chronicles info`
- `/chronicles profile`
- Player profile foundation
- Player join event
- Configurable welcome message

## Development direction

The project is being built as a modular server platform rather than a collection of unrelated commands.

Planned systems:

1. Persistent player profiles
2. Experience and progression
3. Economy
4. Quests and objectives
5. NPCs and dialogue
6. World events
7. Player choices that affect the world
8. Permissions and administration
9. Data storage
10. Performance and production hardening

## Build

Use Java 25 and Gradle:

```bash
./gradlew build
```

The resulting plugin JAR will be placed in `build/libs/`.
